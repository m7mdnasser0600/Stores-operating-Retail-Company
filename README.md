# Retail Sales & Business Intelligence Analytics

An end-to-end **Business Intelligence and Retail Analytics project** developed in Power BI to analyze sales performance, profitability, customer behavior, product performance, store operations, regional trends, and product returns.

The project transforms retail transaction data into an interactive analytical solution, combining **data modeling, DAX measures, time-based analysis, KPI development, and interactive data visualization** to provide a comprehensive view of business performance.

### Key Analytical Areas

* **Executive Performance:** Revenue, orders, profit, profit margin, revenue trends, regional performance, brand performance, and store-type analysis.
* **Sales & Product Analytics:** Units sold, Average Order Value (AOV), top and bottom-performing brands, product characteristics, and store performance.
* **Customer & Regional Insights:** Customer distribution by geography, income, occupation, education, membership status, and customer-level performance.
* **Returns Analysis:** Return volume and value, return rates, return trends, store-level returns, and brand-level return performance.
* **Time-Based Analysis:** Year-over-year performance comparisons and growth analysis across key business metrics.

### Data & Technical Implementation

The solution is built around a structured analytical model containing dedicated dimensions for **customers, products, stores, regions, and calendar dates**, connected to sales and returns data.

A comprehensive set of **DAX measures** was developed to calculate core KPIs and analytical metrics, including:

* Total Revenue
* Total Profit & Profit Margin
* Total Orders & Units Sold
* Average Order Value
* Total Customers & Customer Metrics
* Revenue, Profit, Orders, Units, Stores, and Customer YoY Growth
* Return Rate & Return Value
* Average Return Value
* Revenue per Customer
* Orders per Customer

Interactive filters, dynamic metric analysis, and drill-oriented visualizations allow users to explore the data from multiple business perspectives.

### Tools & Technologies

**Power BI · DAX · Power Query · Data Modeling · Business Intelligence · Data Visualization**

This project demonstrates an end-to-end **data analytics workflow**, from data preparation and dimensional modeling to KPI development, analytical calculations, interactive visualization, and business performance analysis.
